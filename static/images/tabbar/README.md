# 底部标签栏图标

此目录需要添加以下图标文件：

- home.png - 首页未选中图标
- home-active.png - 首页选中图标
- trend.png - 趋势未选中图标
- trend-active.png - 趋势选中图标
- calculator.png - 计算未选中图标
- calculator-active.png - 计算选中图标
- calendar.png - 日历未选中图标
- calendar-active.png - 日历选中图标

图标建议尺寸：64x64px，透明背景。
未选中图标颜色建议使用：#8E8E93
选中图标颜色建议使用：#FF7B31

## 占位图片说明

在实际图标制作完成前，可以使用以下方法创建简单的占位图标：

1. 创建64x64像素的透明背景图片
2. 绘制简单的图形表示各功能：
   - 首页：房子形状
   - 趋势：折线图形状
   - 计算：计算器形状
   - 日历：日历形状
3. 未选中状态使用灰色(#8E8E93)
4. 选中状态使用橙色(#FF7B31)

这些占位图标仅用于开发阶段，后续应替换为设计完成的正式图标。

请将相应图标文件放置在此目录下，以确保底部标签栏正常显示。
